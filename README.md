# React + TypeScript + Vite

## Requirement

- [Docker](https://www.docker.com/)
- [Node](https://nodejs.org/en)(This was made in v20)
- [Typescript](https://www.typescriptlang.org/)

## Installation

You can run it using the following ways

### Using docker

1.  Clone the repo

```
git clone https://github.com/thapasubham/frontend.git
```

2. Ensure you have installed Docker.
3. Enter the directory and run the following command

```
cd frontend
docker-compose up --build -d
```

### Using node

- Clone this Repo

```
git clone https://github.com/thapasubham/frontend.git
```

- Navigate to the project directory

```
cd frontend
```

- Install the dependencies

```
npm install
```

- Run the projects

```
npm run start
```

### You should be able to access it at

```
http://localhost:5000/
```
